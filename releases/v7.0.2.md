# v7.0.2 - 收口残留的写法口径并保住设定事实

## 发版范围

本次发布覆盖 `v7.0.1..v7.0.2`。

## 给作者看的变化

- 设定集里写「北境战争节奏」「死寂氛围」「契约反转」这类世界规则，会进入长期一致性 canon，不再被当成写作教程丢掉。
- 审查只查设定、时间线、连贯、角色与逻辑；查询合同时以卷目标、章纲必须覆盖节点和设定快照为准，不再按节奏策略或动态上下文理解项目。
- 章节摘要和面板不再示范或返回钩子强度；文风仍只看本轮要求和书项目里的文风提示词。
- 作者已经写进设定、总纲和已接受章节的事实会保留进合同，不会被文风词表误删。

## 安装方式

新安装继续按 README 将本仓库作为本地 Cursor 插件目录载入。仓库地址使用 <https://github.com/Splittinglv/canon-ledger>。已安装用户更新到本版本后，无需迁移书项目数据。

## 给维护者

- 审查 schema、evals、query skill 与 blocking 裁决去掉 `ai_flavor` / `pacing` / `other` 以及旧合同口径。
- `reference-loading-map.md` 不再把 plan 写成会加载 `conflict-design.md`，也不再指向不存在的 architecture 文档。
- Dashboard 章节趋势接口去掉钩子强度与审查总分；设定同步 `_SETTING_CRAFT_RE` 不再子串匹配节奏、氛围、反转。
- data-agent 摘要示例去掉 `hook_type` / `hook_strength`。
