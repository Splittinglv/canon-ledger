# v7.2.0 - 堵住静默改写，让知识否定检查真正可达

## 发版范围

本次发布覆盖 `v7.1.0..v7.2.0`。

## 给作者看的变化

- 已接受的章节不能再被「审查未通过」的提交悄悄覆盖。
- 只改正文、不重提该章时，写后续章会被拦住，并提示先 `/canon-ledger-write K`。
- 查询伏笔和世界规则按「截至上一章」；写前任务书不再通读整份 `state.json`。
- 伏笔、承诺、关系、破规则必须引用本章原文；推断出的已知事实进确认队列。
- 同名新 ID 进 `/canon-ledger-confirm`；确认展示信息编号，replace 不能换秘密编号。
- 抽全并确认完之后，「账本没有获得记录」可以自动当成穿帮。审查疑点全部进 `/canon-ledger-confirm`；写完一章后确认是唯一下一步。
- 写章不再把钩子 / CBN 当硬约束。开书不说就不问读者、平台、感情线。

## 安装方式

新安装继续按 README 将本仓库作为本地 Cursor 插件目录载入。已安装用户更新到本版本后，无需迁移书项目数据。

## 给维护者

- `persist_commit` 拒绝 accepted←rejected；prewrite / review-pipeline 检查前缀正文绑定。
- 状态旧值链覆盖状态事件；硬约束事件强制引文；`inferred` 强制 pending。
- 同名新实体转人工；队列与正史同 ID 以队列为准；replace 锁定 `information_id`。
- as-of 在 coverage complete 且无 pending 时聚合为 `verified`；全部事实维 `manual_checks` 进 confirm 队列。
