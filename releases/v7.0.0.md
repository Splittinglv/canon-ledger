# v7.0.0 - 叙典 CanonLedger 产品线起点

## 发版范围

本次发布覆盖 `v6.2.2..v7.0.0`。产品从“Webnovel Writer for Cursor”重品牌为 **叙典 CanonLedger**，并采用生成式 AI 辅助开发与验证；历史来源、GPL-3.0 许可和第三方归属继续完整保留。

## 给作者看的变化

- 产品定位明确为“长篇小说一致性引擎”：守住设定、时间线、人物状态、伏笔、章纲与正文绑定，不替作者或模型决定文风。
- Cursor 插件身份改为 `canon-ledger`，发布账号为 Splittinglv。
- 新安装路径、命令、环境变量与全局配置统一使用 `canon-ledger`。
- 新项目运行目录统一为 `.canon-ledger/`；`.story-system/` 作为品牌中性的故事事实合同目录保留。
- README 将当前产品身份与历史来源分开；上游作者、固定基线、派生范围及许可证集中记录在 NOTICE 与 ATTRIBUTION 中。

## 安装方式

本版本作为全新产品安装，不提供旧插件项目的自动迁移或兼容入口。请用 `/canon-ledger-init` 创建新项目；新项目的正文、设定集、大纲、提交与读模型全部使用 CanonLedger 当前合同。

## 给维护者

- Git 仓库更名为 `Splittinglv/canon-ledger`，并同步 homepage、repository 与安装示例。
- `CANON_LEDGER_*` 是唯一的产品环境变量前缀；Cursor 提供的宿主变量只用于定位当前插件和工作区。
- 包校验必须同时验证产品身份、发布账号、GPL LICENSE、历史来源、归属说明和第三方依赖声明。
- 上游历史只存在于 NOTICE、ATTRIBUTION、CHANGELOG 与旧发行记录中，不再作为当前产品宣传身份。

## 验证

- 运行全量 Python 测试，确认新建小说项目、投影重放、备份恢复和运行时防护不因重品牌回退。
- 运行快速中文行为评估，确认写作流程仍只维护长期一致性。
- 运行严格插件包校验、版本同步检查和发行说明校验。
- 运行品牌扫描，确认 manifest、marketplace、Dashboard、README 与运行时只使用 CanonLedger；旧名仅存在于历史来源文件和冻结的旧版本记录。
