# v7.1.0 - 人工确认走对话、提交链与确认链全链路加固

## 发版范围

本次发布覆盖 `v7.0.2..v7.1.0`。

## 给作者看的变化

- 新增 `/canon-ledger-confirm N`：章末排队的歧义候选事实直接在对话里逐条确认，看证据原文选 confirm / ignore / replace，不再手写裁决 JSON 或手动重跑提交。
- 裁决保存后自动重放本章提交：已确认事实升级为 `verified` 进入正史，故事资料自动重建；正文改过的章节会被拒绝重放并提示重新 `/canon-ledger-write`。
- 提交不再静默半途而废：故事资料没跟上正史会立刻报错并给出修复命令，下次写作前也会检查缺口并阻断。
- 确认真正生效才算完成：报告区分「已裁决未生效」与「已生效」；重复运行确认不会把已确认事实降级。
- 确认单与章节内容、候选内容双重绑定，跨章同名确认单不会串单；replace 锁定事件类型与主体且必须带正文证据。
- 同一信息编号同章两种说法直接报错，跨章说法不一致转人工确认；状态旧值链、实体类型稳定性、全事件证据入章均有确定性校验。
- 写章和审查的最终报告在有待确认项时直接给出 `/canon-ledger-confirm N` 命令。
- 起草约束更明确：占位正文、时间无故回跳、未闭合问题无承接、能力道具情报超出记录，都会在起草阶段就被要求避免。
- Skill 命令块自带环境自检：未在同一 shell 会话执行引导块时给出明确中文报错，不再随机失败。

## 安装方式

新安装继续按 README 将本仓库作为本地 Cursor 插件目录载入。仓库地址使用 <https://github.com/Splittinglv/canon-ledger>。已安装用户更新到本版本后，无需迁移书项目数据。

## 给维护者

- `chapter-commit` 新增 `--from-last-commit`：从该章 commit 文件内保存的四份 artifact 重放 `build_commit`，与四个 artifact 路径参数互斥；重放前仍校验正文绑定，失效即拒绝。
- `chapter_commit.py` 在投影异常或 accepted commit 投影未全部完成时非零退出并输出 `projections retry` 修复指引；新增 `projection_coverage_gaps` 检测投影缺口，prewrite gate 阻断、快照重建消费。
- `human_review` 裁决绑定候选指纹与 verified 内容哈希，`decision_id` 按章节命名空间（resolve 接受无歧义短 ID），replace 校验事件身份与证据，重放幂等不降级。
- `chapter_commit_service` 新增 information_id 冲突检测（同章硬错、跨章转人工）、state_delta 旧值链校验、实体类型稳定性校验，证据入章校验扩展到所有带引用事件；`canonical_history` 允许人工 verified 事件更正既往表述。
- 新增受信引导脚本 `scripts/bootstrap_env.py`（复用 `export_cursor_env.py` 清单校验，输出六行行协议）；9 个 SKILL.md 引导样板收敛为逐字一致的 28 行短样板，并新增一致性测试防再漂移。
- 9 个 SKILL.md 的 59 个非引导 bash 块首行注入环境守卫行；hooks 将逐字一致的守卫行视为判定透明前缀，改写变体不豁免。
- `hooks/guard_runtime_write.py` 白名单加入 `bootstrap_env.py`，`$_EXPORTER` 旧分支替换为对新引导块的逐字放行。
- `user-report` 新增 `confirm` 阶段并报告「裁决已保存但尚未生效」；核心命令/Skill 集从 8 个扩为 9 个。
- 删除挂空的 `references/shared/core-constraints.md`，其防幻觉硬约束并入 write skill Step 2。
