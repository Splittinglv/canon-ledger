# v9.0.0 - Canon 事实准入、能力与读取闭包

## 发版范围

发布日期：2026-08-24

本次发布覆盖 `v8.1.0..v9.0.0`。它把章节候选、legacy 迁移、初始化设定、
managed author axioms、公开 CLI、Hook、Query、Context 与 Dashboard 收口到同一组
可验证不变量，避免软内容从另一条入口重新进入活动 Canon。

## 给作者看的变化

### 事实准入

- 所有能够进入活动 Canon 的章节事实、迁移事实、初始化事实和 author axiom 都必须
  通过统一 fact-boundary policy；已知文风、文笔、节奏、人物动机、人格、人设、
  成长弧、一般因果和软大纲不能生成 Canon effect。
- 自由字段或自由规则语义不再因为“没有命中软关键词”自动成为硬事实；无法结构化
  证明时 fail closed，并要求人工分类或改写。
- 旧人工确认 receipt 只证明历史决定存在，不再替代当前的事实分类。
- 已知 advisory 不能通过普通 `approve` 提升成 Canon；对 ambiguous 值，只有边界专用的
  exact case 才允许作者用 `approve` 将该 digest 明确分类为客观故事事实。
- 现有 v8.1 HEAD 若含不符合新 policy 的活动事实，会进入可诊断的重新认证状态；
  在完成安全清理前，写作、事实查询和 projection 不会回退 legacy 数据继续运行。

### CLI 与 Hook 能力闭包

- 可信统一 CLI 不再只按脚本名和子命令放行；所有带路径的公开写入都同时校验
  project binding、固定工件角色和保留路径。
- `chapter-binding` 与 `memory-contract export-asof` 只能写入登记的
  `.canon-ledger/tmp/` 派生工件，不能覆盖 CURRENT、STAGING、对象库、正文或项目外文件。
- clean init 拒绝位于已有书项目、`.story-system`、`.canon-ledger`、`.cursor`、
  `.git` 或插件根内部的目标。
- `story-events` 公开入口退役；旧 event/index 只保留给显式 migration audit，不能作为
  当前写作事实查询。

### 统一读取面

- CLI Query、Memory Context 和 Dashboard 共享 HEAD/generation/workflow/as-of 绑定的
  active Canon 视图。
- Dashboard facts/history 包含已准入的 genesis、迁移基础事实、章节事实和 author
  axioms，同时继续排除 raw legacy、STAGING 与 style。
- stale projection、迁移中、重新认证中或读中 authority 变化时统一 fail closed，
  不把错误转换为空列表。
- `memory-contract` 的实体、规则、开放问题、obligation 与时间线窄查询也遵守同一规则；
  authority 不可用时非零退出并返回 `usable_for_writing=false`。

## 安装方式

新安装继续按 README 将仓库作为本地 Cursor 插件载入，并安装 Python 与 Dashboard
依赖；本仓库不需要 `.codex-plugin` manifest。升级现有书项目前先备份。

### 升级说明

1. 升级后先运行 `canon-v3 status`。
2. 若返回重新认证或迁移状态，只执行同一份 snapshot 的 `primary_action`；不要运行
   退役的 `story-events`、legacy adapter、chapter-commit 或 projection replay。
3. unresolved 项可以增加人工分类；这是预期的安全成本，不应通过恢复旧读面规避。
4. 旧 HEAD、commit、decision 和证据对象保持不可变并可审计；新 policy 不原地重写
   历史对象。

## 给维护者

- `fact-boundary/v2` 的分类、精确人工决定与存量证明属于权威协议，后续不能只更新
  prompt/Skill 而跳过 compiler、migration、workflow 和 public read 的闭环验证。
- 固定 tmp 输出是命令能力的一部分；Hook 只负责前置拒绝，CLI/runtime 必须独立复验
  exact project role、symlink 和原子替换。
- Dashboard、Query 与 Context 必须从同一 fresh HEAD bundle 派生；历史来源标签不授予
  raw legacy 数据当前权威。
