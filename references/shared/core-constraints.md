## 三大定律（必须精确执行）

| 定律 | 规则 | 检查方式 |
|------|------|----------|
| **大纲给方向** | 按大纲组织剧情；偏离单独报告，默认不冒充事实穿帮 | fulfillment 对照大纲 |
| **设定即物理** | 实力/招式/物品 ≤ 已记录事实 | 写作前查询确认 |
| **发明需识别** | 新实体由 Data Agent 自动提取 | 章节完成后处理 |

## 新实体处理

1. **写作时**: 直接写纯正文，新角色/地点/物品正常描写
2. **完成后**: Data Agent 自动识别新实体并写入索引
3. **不确定实体/事实**: Data Agent 放入人工队列，确认前不写入 canon，也不阻断普通章节

## 硬约束

- 禁止输出占位正文（如 `[待补充]`、`[TODO]`、`...（省略）...`）。
- 能力、道具、情报按明确正向记录保持一致；只有覆盖完整且已验证时才根据“缺失”断言不存在。
- 时间不得无故回跳；倒计时必须推进。
- 若上章留下明确未闭合问题，本章应有承接（允许部分兑现）。

文风优先级为本轮明确要求 > 书项目 `设定集/文风提示词.md` > 模型默认。本文件不规定或检查口吻、句长、修辞或章末钩子。

</instructions>
